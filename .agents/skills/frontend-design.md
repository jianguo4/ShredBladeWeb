# Frontend Design Skill

## Description
Create distinctive, production-grade frontend interfaces using modern design principles, accessibility best practices, and component-based architecture.

## Activation
This skill is automatically activated for all agents (Claude Code, Cline, CodeBuddy, etc.) and provides design guidance for:
- Component design and structure
- Responsive layout patterns
- Color and typography systems
- Accessibility (A11y) standards
- Tailwind CSS integration
- React component best practices

## Usage

### In Chat
```
/skill frontend-design
Describe your design requirement
```

### In Code/Agent
When working on frontend components, this skill provides:
1. **Design Analysis** - Review current UI/UX and identify improvements
2. **Component Suggestions** - Recommend component patterns and structures
3. **Styling Guidance** - Tailwind CSS and CSS best practices
4. **Accessibility Check** - WCAG compliance and a11y improvements
5. **Responsive Design** - Mobile-first and responsive patterns

## Best Practices

- Always request specific design elements or pages
- Provide context about your project stack (React, Vite, Tailwind)
- Include user requirements and target audience
- Ask for accessibility considerations
- Request responsive design guidance
