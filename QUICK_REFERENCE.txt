┌─────────────────────────────────────────────────────────────────────────────┐
│ 🆘 快速故障排除                                                               │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                               │
│  ❌ "无法找到 Puppeteer"                                                      │
│     → npm install puppeteer fs-extra                                        │
│                                                                               │
│  ❌ "无法连接到开发服务器"                                                    │
│     → 确保在另一个终端运行 npm run dev                                        │
│     → 验证服务器在 http://localhost:5173 运行                                │
│                                                                               │
│  ❌ "PowerShell 执行策略错误"                                                │
│     → Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser │
│     或 → 使用批处理脚本 (generate-screenshots-quick.bat)                     │
│                                                                               │
│  ❌ "生成的长图为空白"                                                        │
│     → 增加等待时间，编辑脚本 waitForTimeout 值                                │
│     → 删除 .puppeteer 目录，重新运行                                         │
│                                                                               │
